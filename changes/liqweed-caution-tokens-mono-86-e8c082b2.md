### Added

- Four style tokens for a scene that says more than "reached" and "the one marker": `caution` (a shared concern, a regression) and `alert` (a failure, a struck-out idea), each with the colour for text on it, `onCaution` and `onAlert`. A style sets them in `light` and `dark` like any token; a style that does not gets neutral's (a yellow-gold and a red, apart from `emphasis`), so every existing style and scene renders exactly as before, byte for byte in exports, PNG and video. An unknown token name still throws. The gate holds the style to the pairs a scene draws, as for the other tokens: `caution` and `alert` at 3:1 on the canvas, `onCaution` and `onAlert` at 4.5:1 on their fills. A scene that uses one of the four declares the pair in `contrastPairs` (`kit.sharedPairs("caution/bg", "onCaution/caution")`) or the gate fails it, and a style that sets one and misses its pair is warned once per run. `kit.OPTIONAL_TOKENS` lists them. **Consumer action:** none; add the tokens to a style to change them.
- A `mono` field in a style, the monospace font stack for metrics, code and coordinates (neutral's by default), which a custom scene reads as `style.mono` from `frame(t, { style })`. The gate fails a `font-family` in a scene that is neither the style's `font` nor its `mono`, so a scene never carries a family of its own. **Consumer action:** a custom scene that wrote its own `font-family` now fails `motion-kit check`; use `style.font` or `style.mono`.
- A generic example, `examples/release-check.scene.mjs`: three release checks come back as an ok, a caution and an alert, with their metrics set in the monospace face. It plays once, holds its final frame, lasts 3.4 s and passes the gate in every format, in English and Dutch, in light and dark. The `animated-diagram` skill's styles and custom-scenes references describe the roles, when to use `caution` or `alert` rather than `emphasis`, and the contrast each pair needs. **Consumer action:** none.
